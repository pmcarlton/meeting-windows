MEETING WINDOWS

Open index.html in a current browser, or visit:
https://pmcarlton.github.io/meeting-windows/

No installation or build is needed. Settings and availability are saved in
this browser and do not sync across devices or hosted copies. Keep the
files together for offline use. The tool describes availability; it does
not book meetings.

Usage, development, and update instructions: README.md
Geographic data attribution and licenses: DATA.md
