MEETING WINDOWS
Snapshot: 2026-10-19

GET STARTED
1. Extract this ZIP completely.
2. Open index.html in a current web browser.
3. Choose your timezone and the other person's timezone.
4. Drag across the week grid to select available times. Use Exact ranges
   for overnight or minute-precision intervals.
5. Copy the generated text to your message.

Keep all the extracted files together. No installation or internet connection
is needed. The tool does not create or book a Zoom meeting.

SAVED PREFERENCES
Settings and availability are stored in this browser, when browser storage
is available. They do not sync to other browsers, devices, or hosted copies.
For directly opened files, storage behavior varies by browser. Moving the
folder may also make previous settings unavailable. Clearing browser data
can remove saved settings and availability.

KNOWN LIMITATION
Long intervals spanning timezone offset changes can produce wording that
needs correction. For now, enter separate ranges on either side of a clock
change and review the generated dates and times before sending.

UPDATES
This is a small utility shared for personal and colleague use, with occasional
updates and no scheduled support. This offline snapshot does not auto-update.
Keep the current browser and operating system updated: timezone conversion
uses the browser's timezone rules. The bundled map and city data remain as
shipped in this snapshot.

DEVELOPMENT AND HOSTING
These are plain HTML, CSS, and JavaScript files. They can also be served by
any static web host, with index.html at the published directory root.
No dependency installation or build is needed.

The source package includes a longer README and regression tests.
Geographic data sources and attribution are in DATA.md and inside the app.
